# Employee Management System

A modern Employee Management System developed using HTML, CSS, JavaScript, Node.js, and Express.js. This application helps manage employee records efficiently with features like adding, editing, deleting, and searching employees through a responsive dashboard interface.

---

## Features

- Add Employee Details
- Edit Employee Information
- Delete Employee Records
- Search Employees
- Responsive Dashboard UI
- Professional Table Design
- User-Friendly Interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
